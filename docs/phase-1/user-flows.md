# User Flows (Draft)

*Owner: Anisa Arora*

Step-level flows only — visual wireframes are a **Week 2** deliverable.

## Farmer
1. Register / Login → complete profile (land size, region, crop type)
2. Search resources by type/location/availability
3. Submit individual or group booking request
4. View booking status (pending / accepted / rejected)
5. Log expense/revenue entry in farm ledger
6. View eligible government schemes → start application
7. Create insurance claim → upload photos/documents → track status

## Resource Provider
1. Register / Login → list a resource with availability + charges
2. View incoming booking requests
3. Accept / reject / reschedule
4. View service history & reputation

## Administrator
1. Login → admin dashboard
2. Manage scheme eligibility rules
3. Monitor listings → flag/remove invalid entries
4. Maintain reference data
